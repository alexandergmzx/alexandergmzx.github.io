A 12-week, hands-on course aimed at engineers who want to use Python as their
day-to-day glue for automation, infrastructure, and CI/CD. Each session mixes
short walkthroughs with live coding on a shared repository.

**Format.** Thursday afternoons, live online, 90 minutes per session. Recordings
and notebooks are shared with the cohort.

**Who it's for.** Software, DevOps, and SRE engineers comfortable with the
basics of Python who want to move from one-off scripts to maintainable tooling.

The spring cohort is in progress. To be notified when the next cohort opens —
or to ask about bringing the course to your team — use the booking link on the
[teaching page](/teaching/).
